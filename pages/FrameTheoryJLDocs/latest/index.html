Frame Theory

FrameTheory.jl is a collection of tools for working with Frames in Julia. A large portion of this package uses the Julia Package Oscar.jl.

This package was originally developed as companion software for the paper [5] to compute frames over finite field, which represent a large majority of the package. Later the packages was expanded to work with frames over real and complex numbers, both using exact arithmetic, and numerical arithmetic.

Current FrameTheory.jl Functionality

  • Frames Exactly
  • Frames Numerically
  • Frames over Finite Fields

Getting Started

Please refer to the Oscar.jl installation instructions here.

Activate and load this package: In the FrameTheory directory

pkg> activate .
pkg> instantiate  # Press ']' to enter the Pkg REPL mode.

Or by running using Pkg; Pkg.activate("."); Pkg.instantiate();.

Then 

julia> using FrameTheory; using Oscar;
